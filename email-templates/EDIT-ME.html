Nervexus digest email — the one file to edit
Below is the email. There is only one — everything outstanding is collected into it, so this same layout has to work whether there are six items or one. Redesign it however you like and send the file back; the renderer gets rebuilt to match.
The moving parts
Four comment markers in the markup below show what is dynamic:
• SECTION BLOCK — repeats once per section. Empty sections are dropped, so any subset can appear, including just one.
• ITEM ROW — repeats once per item inside a section.
• PRIORITY FLAG — appears only on urgent items; absent the rest of the time.
• The small grey line under an item (“15:00 tomorrow”, “v11.227”) is optional too.

The words are samples. Change them freely — the copy is yours. The five section names are fixed: Performance Terminal, Tasks & Missions, Calendar, Logs, App Update.
Rules that are not preferences
Email clients are not browsers. Keep tables for layout and inline styles only — Outlook drops display:flex and display:grid outright, and Gmail strips <style> blocks. No web fonts (a linked font silently becomes Times) and no remote images (most clients block them by default), so anything that matters has to be text. Assume a phone, one column. The test suite checks all of this, so a design that breaks it fails before it reaches an inbox.
